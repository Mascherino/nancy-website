Crops
How it works
You will receive a notification if one of the items mentioned below is ready.
Affected items
Basic crops:
  • Sunflower
  • Potato
  • Rhubarb
  • Pumpkin
  • Zucchini
Medium crops:
  • Carrot
  • Yam
  • Cabbage
  • Broccoli
  • Soybean
  • Beetroot
  • Pepper
  • Cauliflower
  • Parsnip
Advanced crops:
  • Eggplant
  • Corn
  • Onion
  • Radish
  • Wheat
  • Kale
  • Artichoke
  • Barley
Additional information
Setting Value
Active by default All active (except Sunflower)
Toggle alerts using /setalerts Crops
Affected by custom offset Yes
Affected by custom message format Yes
Available on other platforms Yes, see /apprise command
